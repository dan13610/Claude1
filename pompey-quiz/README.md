# Name That Nineties Blue

A three-choice quiz on 1990s Portsmouth FC players. Each round shows up to three clues about a player; guess with one clue for 3 points, two for 2, or all three for 1. Each game picks 10 of 15 players at random.

It's a single self-contained web page. Open `index.html` in any browser, phone included — no build step or install needed.

## Adding players

Players live in the `PLAYERS` list near the top of the script in `index.html`. Each entry has a name, a position (`GK`, `DF`, `MF` or `FW`, used to pick believable wrong answers) and three clues, from vaguest to most obvious.

Clue facts were checked against each player's Wikipedia article.
